Install

Get started in 10 seconds

Three ways to install. Pick whichever you prefer.

01 · Homebrew

🍫 Homebrew

Recommended — one command, auto-updates via brew.

brew install --cask mac-closed-awake
02 · DMG

💿 Direct Download

Grab the latest .dmg from GitHub Releases and drag to Applications.

# open the latest release page open https://github.com/onezion12344/mac-closed-awake/releases
03 · Source

🔧 Build from Source

Clone, install, run. Electron does the rest.

git clone https://github.com/onezion12344/mac-closed-awake.git cd mac-closed-awake npm install && npm start
