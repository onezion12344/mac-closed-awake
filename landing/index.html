Install

Get started in 10 seconds

Three ways to install. Pick the one that feels easiest.

01 · Homebrew (Recommended)

🍫 Homebrew — the simplest way

Just paste this one command and press Enter. Homebrew handles everything. Updates via brew upgrade.

brew install --cask mac-closed-awake
🤔 What is Homebrew?

A free, trusted app installer for Mac — used by millions. Think of it as an "App Store for developers." Visit brew.sh to learn more or install it.

02 · Direct Download

💿 Download and drag — no commands needed

Don't want the command line? Download the app file and drag it into Applications.

  1. Go to the latest release page.
  2. Click the .dmg file to download.
  3. Double-click the downloaded file to open.
  4. Drag MacClosedAwake.app into Applications.
  5. Open from Applications. Done! 🎉
03 · For Developers Only

🔧 Build from Source

For developers who want to run from source or contribute. Requires Node.js and Git.

git clone https://github.com/onezion12344/mac-closed-awake.git cd mac-closed-awake npm install && npm start

🐑 Not sure which to pick?

Homebrew (Option 1) is the easiest — one command handles everything. Never used the command line? Try Direct Download (Option 2) — just drag and drop.

🖥️ How to open Terminal (终端) — for first-time users

To run the Homebrew command, open the Terminal app on your Mac:

  1. Spotlight (fastest): Press Command + Space, type Terminal or 终端, press Enter.
  2. Finder: Applications → Utilities → Terminal.
  3. Launchpad: Search for Terminal.
💡 macOS says "Terminal wants to access..."? That's normal! Click "OK" — it's a standard permission prompt.
Then: Copy the brew install --cask mac-closed-awake command, paste it into Terminal, and press Enter. Done!
